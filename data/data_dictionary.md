# Data Dictionary — `stress_dataset.csv`

Synthetic dataset for **"An LLM-powered application for detecting stress levels in Vietnamese university students"**.
Generated by [`app/generate_dataset.py`](../app/generate_dataset.py) (reproducible with `--seed`). Each record is driven by one latent stress level so all feature groups are mutually consistent.

Encoding: UTF-8 with BOM (opens correctly in Excel). 75 columns, grouped as below.

## 1. Metadata / demographics

| Column | Type | Values / Range | Notes |
|---|---|---|---|
| `student_id` | string | `SV0001`… | Mã định danh (giả lập, không phải dữ liệu thật) |
| `age` | int | 18–23 | Tương quan với năm học |
| `gender` | categorical | Nam / Nữ / Khác | |
| `academic_year` | int | 1–5 | Năm đang học |
| `major` | categorical | 8 ngành (CNTT, Kinh tế, Y khoa, …) | |
| `gpa` | float | 2.0–4.0 | Thang 4; tương quan âm nhẹ với stress |
| `living_situation` | categorical | Sống cùng gia đình / Ký túc xá / Ở trọ | |
| `has_part_time_job` | int (0/1) | 0–1 | Có đi làm thêm |

## 2. Free text (main LLM input)

| Column | Type | Notes |
|---|---|---|
| `free_text` | string (tiếng Việt) | 2–4 câu tự thuật về trạng thái tinh thần; nhắc đến stressor nổi bật nhất và cách ứng phó của sinh viên. Input chính cho LLM. |

## 3. Emotion-model features (HuggingFace)

Mô phỏng đầu ra của `app/emotion.py` (model `j-hartmann/emotion-english-distilroberta-base`).

| Column | Type | Range | Notes |
|---|---|---|---|
| `emotion_fear`, `emotion_sadness`, `emotion_anger`, `emotion_joy`, `emotion_neutral`, `emotion_disgust`, `emotion_surprise` | float | 0–1 | Xác suất 7 cảm xúc, tổng ≈ 1 |
| `dominant_emotion` | categorical | 7 nhãn trên | Cảm xúc có xác suất cao nhất |
| `emotion_stress_score` | float | 0–1 | Cùng công thức trọng số với `emotion.py`: 0.4·fear + 0.35·sadness + 0.25·anger + 0.1·disgust − 0.3·joy, clip [0, 1] |

## 4. DASS-21 (Lovibond & Lovibond)

Chấm điểm bằng `app/dass21.py`.

| Column | Type | Range | Notes |
|---|---|---|---|
| `dass21_q1` … `dass21_q21` | int | 0–3 | Điểm từng câu theo thang trả lời chuẩn |
| `dass21_depression_score` / `dass21_anxiety_score` / `dass21_stress_score` | int | 0–42 | Tổng item của subscale × 2 (quy tắc chính thức) |
| `dass21_depression_severity` / `dass21_anxiety_severity` / `dass21_stress_severity` | categorical | Normal / Mild / Moderate / Severe / Extremely Severe | Theo ngưỡng chính thức từng subscale |
| `dass21_overall_severity` | categorical | như trên | Mức nặng nhất trong 3 subscale |

Subscale mapping: Depression = q3, q5, q10, q13, q16, q17, q21 · Anxiety = q2, q4, q7, q9, q15, q19, q20 · Stress = q1, q6, q8, q11, q12, q14, q18.

## 5. PSS-10 (Cohen's Perceived Stress Scale)

| Column | Type | Range | Notes |
|---|---|---|---|
| `pss_q1` … `pss_q10` | int | 0–4 | **Điểm thô như người trả lời chọn.** Item 4, 5, 7, 8 là câu tích cực — khi tính tổng phải đảo điểm (score = 4 − raw) |
| `pss_total_score` | int | 0–40 | Tổng sau khi đảo điểm item 4, 5, 7, 8 |
| `pss_stress_category` | categorical | Low (0–13) / Moderate (14–26) / High (27–40) | Ngưỡng chuẩn |

## 6. Stress sources & coping resources (Likert 1–5)

1 = hoàn toàn không đúng/không có · 5 = rất đúng/rất thường xuyên.

### 6a. Academic stressors
`acad_course_load` (khối lượng bài tập/deadline), `acad_exam_pressure` (áp lực thi cử), `acad_fear_of_failure` (sợ rớt môn), `acad_time_management` (khó sắp xếp thời gian), `acad_english_pressure` (chuẩn đầu ra tiếng Anh).

### 6b. Lifestyle stressors
`life_financial_pressure` (tài chính), `life_family_expectation` (kỳ vọng gia đình), `life_relationship_stress` (quan hệ/tình cảm), `life_sleep_problems` (thiếu ngủ), `life_health_concerns` (sức khỏe).

### 6c. Coping resources (điểm cao = nguồn lực tốt, tương quan âm với stress)
`cope_family_support` (hỗ trợ gia đình), `cope_friend_support` (hỗ trợ bạn bè), `cope_exercise` (thể dục thể thao), `cope_hobbies` (sở thích giải trí), `cope_professional_help` (tư vấn tâm lý chuyên nghiệp).

## 7. Output / labels (for training & evaluation)

| Column | Type | Values | Notes |
|---|---|---|---|
| `stress_label` | categorical | Low / Moderate / High | Nhãn chính, tổng hợp từ 2 thang đo chuẩn hóa: DASS-21 stress severity (Normal+Mild→0, Moderate→1, Severe+Ex.Severe→2) và PSS category (0/1/2), lấy trung bình làm tròn |
| `stress_label_binary` | int (0/1) | 1 = Moderate/High | Cho bài toán phân loại nhị phân |

## Regenerating

```bash
python app/generate_dataset.py --rows 500 --seed 42 --out data/stress_dataset.csv
```

> **Lưu ý:** đây là dữ liệu tổng hợp (synthetic) dùng để phát triển pipeline. Khi khảo sát dữ liệu thật, giữ nguyên schema này để thay thế trực tiếp.
