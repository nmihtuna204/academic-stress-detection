# Data Dictionary — `stress_dataset.csv`

Synthetic dataset for **"An LLM-powered application for detecting stress levels in Vietnamese university students"**.
Generated by [`research/generate_dataset.py`](../research/generate_dataset.py) (reproducible with `--seed`). Each record is driven by one latent stress level so all feature groups are mutually consistent.

Encoding: UTF-8 with BOM (opens correctly in Excel). 75 columns, grouped as below.

> **Language note.** The application interface is English, but the categorical values and free text in this file are **Vietnamese**, exactly as generated. This dataset is the frozen split the PhoBERT classifier was fine-tuned on and every classification result in the report was measured against; regenerating it in English would produce a different corpus and invalidate those results. The values below are documented as they actually appear in the CSV, with English glosses.

## 1. Metadata / demographics

| Column | Type | Values / Range | Notes |
|---|---|---|---|
| `student_id` | string | `SV0001`… | Identifier (simulated, not real data) |
| `age` | int | 18–23 | Correlated with year of study |
| `gender` | categorical | `Nam` (Male) / `Nữ` (Female) / `Khác` (Other) | |
| `academic_year` | int | 1–5 | Current year of study |
| `major` | categorical | 8 fields (Information Technology, Economics, Medicine, …) | Stored in Vietnamese |
| `gpa` | float | 2.0–4.0 | 4-point scale; slight negative correlation with stress |
| `living_situation` | categorical | `Sống cùng gia đình` (with family) / `Ký túc xá` (dormitory) / `Ở trọ` (rented room) | |
| `has_part_time_job` | int (0/1) | 0–1 | Whether the student works part-time |

## 2. Free text (main LLM input)

| Column | Type | Notes |
|---|---|---|
| `free_text` | string (Vietnamese) | 2–4 self-descriptive sentences about mental state; mentions the most prominent stressor and the student's coping response. The main LLM input. |

## 3. Emotion-model features (HuggingFace)

Simulates the output of the emotion model (`j-hartmann/emotion-english-distilroberta-base`), the approach kept in `research/emotion_en.py`.

| Column | Type | Range | Notes |
|---|---|---|---|
| `emotion_fear`, `emotion_sadness`, `emotion_anger`, `emotion_joy`, `emotion_neutral`, `emotion_disgust`, `emotion_surprise` | float | 0–1 | Probabilities of the 7 emotions, summing to ≈ 1 |
| `dominant_emotion` | categorical | one of the 7 labels above | The emotion with the highest probability |
| `emotion_stress_score` | float | 0–1 | Same weighting formula as the emotion module: 0.4·fear + 0.35·sadness + 0.25·anger + 0.1·disgust − 0.3·joy, clipped to [0, 1] |

## 4. DASS-21 (Lovibond & Lovibond)

Scored by [`app/scoring/dass21.py`](../app/scoring/dass21.py).

| Column | Type | Range | Notes |
|---|---|---|---|
| `dass21_q1` … `dass21_q21` | int | 0–3 | Per-item score on the standard response scale |
| `dass21_depression_score` / `dass21_anxiety_score` / `dass21_stress_score` | int | 0–42 | Subscale item sum × 2 (the official rule) |
| `dass21_depression_severity` / `dass21_anxiety_severity` / `dass21_stress_severity` | categorical | Normal / Mild / Moderate / Severe / Extremely Severe | Per the official per-subscale thresholds |
| `dass21_overall_severity` | categorical | as above | The most severe of the 3 subscales |

Subscale mapping: Depression = q3, q5, q10, q13, q16, q17, q21 · Anxiety = q2, q4, q7, q9, q15, q19, q20 · Stress = q1, q6, q8, q11, q12, q14, q18.

## 5. PSS-10 (Cohen's Perceived Stress Scale)

| Column | Type | Range | Notes |
|---|---|---|---|
| `pss_q1` … `pss_q10` | int | 0–4 | **Raw scores as the respondent chose them.** Items 4, 5, 7 and 8 are positively worded — the total must reverse them (score = 4 − raw) |
| `pss_total_score` | int | 0–40 | Total after reverse-scoring items 4, 5, 7, 8 |
| `pss_stress_category` | categorical | Low (0–13) / Moderate (14–26) / High (27–40) | Standard thresholds |

## 6. Stress sources & coping resources (Likert 1–5)

1 = does not apply at all / not present · 5 = applies strongly / very frequent.

### 6a. Academic stressors
`acad_course_load` (assignment/deadline workload), `acad_exam_pressure` (exam pressure), `acad_fear_of_failure` (fear of failing a course), `acad_time_management` (difficulty managing time), `acad_english_pressure` (English graduation requirement).

### 6b. Lifestyle stressors
`life_financial_pressure` (finances), `life_family_expectation` (family expectations), `life_relationship_stress` (relationships), `life_sleep_problems` (lack of sleep), `life_health_concerns` (health).

### 6c. Coping resources (a high score means good resources, negatively correlated with stress)
`cope_family_support` (family support), `cope_friend_support` (support from friends), `cope_exercise` (exercise and sport), `cope_hobbies` (hobbies and leisure), `cope_professional_help` (professional psychological support).

## 7. Output / labels (for training & evaluation)

| Column | Type | Values | Notes |
|---|---|---|---|
| `stress_label` | categorical | Low / Moderate / High | The main label, combining 2 normalised scales: DASS-21 stress severity (Normal+Mild→0, Moderate→1, Severe+Ex.Severe→2) and PSS category (0/1/2), averaged and rounded |
| `stress_label_binary` | int (0/1) | 1 = Moderate/High | For the binary classification task |

## Regenerating

```bash
python research/generate_dataset.py --rows 500 --seed 42 --out data/stress_dataset.csv
```

> **Note:** this is synthetic data used to develop the pipeline. When collecting real data, keep this schema so it can be substituted directly.
